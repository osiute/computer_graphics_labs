## Формат входного файла:
Для данной лабораторной работы (в целях экономия времени и избавления от постоянного переписывания в интерактивном режиме одних и тех данных во время отладки) программа запрашивает лишь название файла (.txt), в котором записаны вершины многоугольников, а не каждую вершину по отдельности.

W H          // Ширина и высота изображения
N            // Количество вершин исходного многоугольника
x1 y1        // Вершина 1
x2 y2        // Вершина 2
...
M            // Количество вершин отсекающего окна
x1 y1        // Вершина окна 1
x2 y2        // Вершина окна 2
...

## Выходной файл
Результатом работы программы является выходной файл растрового изображения (.ppm), где чётко видны границы исходного многоугольника, границы отсекающего окна, а также залитая область исходного многоугольника.
