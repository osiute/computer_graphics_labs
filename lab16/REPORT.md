**Тема:** форматы хранения 3D-графики, OBJ и MTL.

## Цель

Загрузить полигональную 3D-модель в формате OBJ вместе с цветами материалов MTL, отобразить закрашенные поверхности с корректным определением видимости и сохранить результат в PNG.

## Исходные данные

Используется дом из `lab15/obj/house.obj` — 10 вершин и 7 полигональных граней. Копия геометрии с назначением материалов находится в `lab16/assets/house.obj`; библиотека цветов — `lab16/assets/house.mtl`. Исходные координаты и индексы граней сохранены.

| Материал | Грани | Цвет `Kd` |
| --- | --- | --- |
| `Walls` | Торцевые стены | `0.86 0.67 0.36` |
| `Sides` | Боковые стены | `0.25 0.48 0.72` |
| `Roof` | Крыша | `0.72 0.24 0.16` |
| `Foundation` | Основание | `0.40 0.43 0.48` |

## Реализация

Приложение написано на C++17 и собирается CMake. Загрузчик читает вершины и грани OBJ, проверяет индексы, находит MTL относительно OBJ и сохраняет назначения `usemtl`. Цвет берётся из `Kd` соответствующего блока `newmtl`. Для отсутствующих материалов используется стандартный цвет с предупреждением.

Геометрические структуры и перспективная проекция переиспользованы из `common_utils`. Модель центрируется, масштабируется и поворачивается на заданные пользователем углы. Полигональные грани триангулируются методом отсечения ушей. Растеризатор использует барицентрические координаты и интерполяцию обратной глубины в Z-буфере, сохраняя ближайшую поверхность в каждом пикселе. Цвет поверхности задаётся материалом без расчёта освещения. Изображение сохраняется в PNG.

## Запуск

Из корня репозитория:

```bash
cmake -S lab16 -B lab16/build -DCMAKE_BUILD_TYPE=Debug
cmake --build lab16/build
ctest --test-dir lab16/build --output-on-failure
./lab16/build/lab16_app lab16/assets/house.obj lab16/build/house.png 35 25 1000 800
```

Для интерактивного режима выполнить `./lab16/build/lab16_app` без аргументов. Инструкция для VS Code находится в `README.md`.
